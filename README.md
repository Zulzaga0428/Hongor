# Япон хэлний сургалт — Хонгор Түрүү

Японд ажиллахаар бэлдэж буй сурагчдын хэлний бэлтгэлийн сайт (khturuu.com-оос ТУСДАА).
Утсанд зориулсан: утасны дугаар + 4 оронтой нууц кодоор нэвтэрч, түвшнээ (анхан N5 / дунд N4 / ахисан N3) сонгоод хичээллэнэ.

## Хэн юу хийдэг вэ
- **Сурагч**: бүртгүүлэх, хичээл үзэх (үсэг/үг дээр дарж япон дуудлага сонсох), тест өгөх (оноог сервер тооцно), даалгавар илгээх, багшийн оноо/сэтгэгдэл харах, түвшин солих.
- **Багш** (`/bagsh`): сурагчдын ахиц түвшнээр, шалгах даалгавар, оноо+сэтгэгдэл өгөх, шинэ даалгавар өгөх.
- **Сурагч → Материал** (`/material`): анкет (улс, хөтөлбөр, ажил, хувийн мэдээлэл, зөвшөөрөл), бичиг баримт хуулах (утсан дээр шахаж илгээнэ), бүртгүүлснээс нисэх хүртэлх 7 шат.
- **Удирдлага** (`/admin`): шат бүрийн тоо, улсаар, хайлт/шүүлт, анкет+баримт харах, баримт батлах/буцаах, шат солих (түүхтэй), ажилтны тэмдэглэл, Excel (CSV) татах.

Баримт Postgres-д (bytea) хадгалагдана, зөвхөн эзэн ба админ харна. Улс/хөтөлбөр/шат: `src/content/programs.ts`.

## Ажиллуулах
```
npm install
npm run build
SESSION_SECRET=... npm start
```
`DATABASE_URL` байхгүй бол дотроо PGlite (`.data/pglite`) ашиглана; байвал Postgres (Neon/Railway).
Хүснэгтүүд эхний ачаалалд автоматаар үүснэ.

| Хувьсагч | Утга |
|---|---|
| `SESSION_SECRET` | ПРОД-д заавал |
| `DATABASE_URL` | Postgres (заавал биш) |
| `TEACHER_PHONE` / `TEACHER_PIN` / `TEACHER_NAME` | Багшийн бүртгэл — сервер асах бүрд тааруулна. ПРОД-д байхгүй бол багш үүсэхгүй (локалд 88888888 / 1234) |
| `ADMIN_PHONE` / `ADMIN_PIN` / `ADMIN_NAME` | Удирдлагын (эгчийн) бүртгэл — горилогч, баримт, шат, Excel. Мөн адил тааруулна (локалд 99999999 / 1234) |
| `SEED_DEMO` | `1` бол 3 жишээ сурагч нэмнэ (локалд анхдагч) |

Хичээлийн агуулга: `src/content/lessons.ts`.
